# Catálogo web sencillo

Página web de práctica que muestra un catálogo de productos con búsqueda por nombre y filtro por categoría. Hecha con HTML, CSS y JavaScript, sin librerías.

> Los productos y precios son ficticios.

## Qué muestra

- Maquetación adaptable a celular con CSS Grid y Flexbox.
- Búsqueda y filtro en vivo con JavaScript.
- Formato de precios en pesos colombianos.

## Cómo verlo

Abre `index.html` en el navegador, o actívalo en GitHub Pages (Settings → Pages → rama `main`).

## Tecnologías

HTML5 · CSS3 · JavaScript
